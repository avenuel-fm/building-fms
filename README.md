# 잠실점 에비뉴엘 시설물 및 배관 통합 관제 시스템 (Avenuel Building FMS)

잠실점 에비뉴엘 백화점의 층별 평면도, 기초 시설물(소방, 급수, 공조, 전기), 그리고 매장별 배관 및 전기 인입 간선을 실시간으로 모니터링하고 관리하는 고성능 Rust 기반 FMS(Facility Management System)입니다.

---

## 🌟 핵심 기능

1. **매장별 인입 배관/전기선 단독 활성화 (Active Flow)**
   - 평면도 상의 매장 구역(샤넬, 에르메스, 루이비통, 디올, 구찌, 롤렉스 등)을 클릭하면, **해당 매장으로 인입된 배관 및 전기 라인만 굵은 선과 애니메이션으로 하이라이트**됩니다.
   - 연결되지 않은 다른 모든 매장 및 비관련 배관/시설물은 **12% 반투명 흑백(Grayscale Dimmed)** 처리되어 직관적인 계통 추적이 가능합니다.
   - 상단 안내 배너의 `[전체 매장 보기 ✕]` 버튼으로 언제든지 전체 평면도로 복귀할 수 있습니다.

2. **Unslop 디자인 표준 준수 (AI Slop 완전 배제)**
   - 버튼/라벨의 불필요한 이모지 배제, 차분한 슬레이트 뉴트럴 톤, 엄격한 **4px 그리드 시스템** 및 1.5px 정밀 벡터 SVG 아이콘 체계 적용.
   - **밝은 테마 (화이트프린트 백상지 CAD)** ↔ **어두운 테마 (다크 엔지니어링 모드)** 원클릭 실시간 토글 지원.

3. **보안 4자리 PIN 인증 및 권한 분기**
   - **관리자 (`PIN: 1234`)**: 시설물/배관 CRUD, 배관 도면 직접 그리기, CAD 업로드, 직원/PIN 관리 전체 권한.
   - **직원 (`PIN: 5678`)**: 뷰어 전용 모드 (도면 조회 및 매장 계통 탐색만 허용, 편집 버튼 자동 차단).

4. **배관 및 전기 라인 직접 그리기 & CAD 지원**
   - 도면을 클릭하여 시작점과 꺾임점을 연결해 연속 배관/전기선을 그리고, 연결 매장을 지정하여 즉시 등록.
   - AutoCAD DXF 파일 업로드 지원 구조.

5. **초경량 고성능 단일 바이너리 (Rust Axum)**
   - 외부 런타임 설치 없이 단 하나의 실행 파일과 웹 에셋으로 즉시 구동.
   - Google Sheets API 양방향 동기화 연동 인터페이스 구비.

## 🏗️ 시스템 아키텍처

- **Backend**: Rust 2021, Axum 0.7, Tokio (비동기 I/O), Tower-HTTP, Serde
- **Frontend**: Vanilla HTML5, CSS Variables (라이트/다크 테마), Tailwind CSS (Standalone), SVG 2D Canvas
- **API Endpoints**:
  - `POST /api/auth/login`: 4자리 PIN 인증
  - `GET /api/shops`: 입점 매장 목록 및 연결 선로 수
  - `GET /api/pipes`, `POST /api/pipes`, `DELETE /api/pipes/:id`: 배관/전기라인 CRUD
  - `GET /api/facilities`, `POST /api/facilities`: 설비 핀 CRUD
  - `GET /api/staff`, `POST /api/staff`: 관리자 전용 직원 목록 및 PIN 등록

## 🚀 로컬 실행 방법

### Windows 원클릭 실행
프로젝트 루트의 `run.bat` 파일을 더블 클릭하면 서버가 시작되고 브라우저가 자동으로 열립니다:
```cmd
run.bat
```

### Cargo 직접 실행
```bash
cargo run
```
서버가 시작되면 브라우저에서 아래 주소로 접속합니다:
👉 **http://127.0.0.1:8080**
